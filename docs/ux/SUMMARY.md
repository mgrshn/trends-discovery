## Shell Architecture

```
semrush.com/app/exploding-topics/pro/*   ← Semrush App Center shell
  └── <iframe src="https://ac.explodingtopics.com/?jwt=...">
        └── Exploding Topics SPA (React, Semrush App Center SDK)
```

JWT token generated by `rp8920cf.semrush.com/v2/rb` on each page load. Token encodes user identity + plan tier + expiry. The iframe app validates it server-side and adjusts feature gates accordingly.

## Reusable UI Components

### Trend Card
Used on: Dashboard (Recommended Trends), Trends Database, Trend Tracking
```
┌─────────────────────────────────────┐
│  Topic Name                         │
│  Short description (optional)       │
│                                     │
│  22.2K         +500%    [sparkline] │
│  Volume        Growth               │
│                                     │
│  [+ TRACK TOPIC]                    │
└─────────────────────────────────────┘
```
Fields: `name`, `volume`, `growth_pct`, `sparkline[]`, `status_badge?`, `description?`

### Sparkline
- 60–90 px wide line chart
- 5-year or plan-selected window
- No axes, no hover in card view
- Color: blue (#4A6CF7 approx)

### Status Badge
- `Exploding` (green / rising arrow)
- `Regular` (grey)
- `Peaked` (orange / falling arrow)
- `Dormant` (grey, minimal activity)

### Filter Bar
Used on: Trends Database, TikTok Insights, Trending Startups, Trending Products
- Horizontal row of `<select>` dropdowns
- Labels above each: TIMEFRAME, CATEGORY, SORT BY, GROWTH, VOLUME, etc.
- All-caps label style, compact height

### Data Table
Used on: TikTok Insights, Trending Startups, Trending Products
- Sticky header row
- Column header click = sort
- Thumbnail + name + description in first column
- Sparklines inline in Growth column
- Right-aligned numeric columns

## Inferred API Contract

All endpoints served from `ac.explodingtopics.com`. Authenticated via JWT in initial iframe URL; subsequent requests use session cookie.

### Topics / Database

```
GET /api/v1/topics
  ?category=business          # slug
  &sort=growth                # growth | volume | newest
  &timeframe=5y               # 1m | 3m | 6m | 1y | 2y | 5y | all
  &type=all                   # all | brands | non-brands
  &volatility=all             # all | volatile | stable
  &page=1
  &limit=20

→ 200 {
    "total": 379547,
    "page": 1,
    "results": [
      {
        "id": "...",
        "name": "Barrier Moisturizer",
        "slug": "barrier-moisturizer",
        "description": "...",
        "categories": ["Beauty", "Skincare"],
        "status": "exploding",        // exploding | regular | peaked | dormant
        "volume": 45500000,
        "growth_pct": 9900,           // +99X+ = ≥9900%
        "sparkline": [12, 15, 18, ...],
        "is_brand": false,
        "volatility": "volatile"
      }
    ]
  }
```
