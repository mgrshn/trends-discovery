## Key Observations for Clone

1. The public-facing API is a paid add-on, not included in any subscription tier
2. Must be on **Business plan** ($249/mo) as a prerequisite to purchase API access
3. API documentation is publicly linked (useful to inspect endpoint shapes without access)
4. Commercial use requires direct contact (no self-serve)
5. Rate limits: 1K / 5K / 25K requests per month — very low compared to Google Trends
