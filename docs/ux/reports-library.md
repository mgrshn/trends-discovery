# Reports Library

**URL:** click "Reports Library" nav item  
**Screenshots:** `reports-library/nav-click.png`

## Observed Behaviour

The "Reports Library" nav item opens a **plan selection / upgrade screen**, not a library of reports. This is a gating page — the Reports Library feature is only available on the Business plan ($249/mo).
